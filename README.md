# customer-data-analysis
Customer Sales Analysis — E-commerce

Introduction

This project analyzes sales and customer data from an e-commerce company selling electronic products. The analysis focuses on customer satisfaction during a discount period and explores patterns that can help the business understand its customers and sales performance.

Project Objectives

- Analyze customer satisfaction ratings.
- Explore sales and customer purchasing patterns.
- Examine factors such as discounts, shipment methods, and customer ratings.
- Present insights through interactive Power BI visualizations.
- Support data-driven business decisions.

Tools Used

- Microsoft Excel: Data inspection and cleaning.
- Microsoft Power BI: Data analysis and visualization.
- PowerPoint / PDF: Presentation of findings.
- GitHub: Project documentation and file storage.

Project Process

1. Imported the dataset.
2. Cleaned and prepared the data.
3. Analyzed relevant sales and customer metrics.
4. Created visualizations in Power BI.
5. Summarized the findings in a presentation.

Key Findings

The analysis examined customer ratings, shipment methods, sales performance, and other customer-related variables.

See the accompanying presentation for the key findings and recommendations based on the analysis.

Conclusion

This project demonstrates how Excel and Power BI can be used to analyze e-commerce data, identify customer patterns, and communicate insights that can support business decisions.
